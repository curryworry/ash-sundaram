Privacy Policy

Last Updated: January 13, 2026
Effective Date: January 13, 2026
Summary: DV360 YouTube Channel Analyzer is a business automation tool that processes DV360 advertising reports to ensure COPPA compliance. We only access emails containing DV360 reports, use publicly available YouTube data, and do not collect or share personal information.

Overview

DV360 YouTube Channel Analyzer is an automation tool developed and operated by Acquire NZ for analyzing YouTube channel placements from Display & Video 360 (DV360) advertising reports.

Application Purpose

This application is designed for business use to:

  • Process DV360 placement reports received via email
  • Analyze YouTube channel content for COPPA compliance and brand safety
  • Generate categorized channel lists for advertising campaign management
  • Automate weekly reporting workflows

Data Collection and Usage

Gmail API Access

What We Access:

  • Emails sent to authorized users with the subject "YouTube Placement Check - DV360"
  • ZIP file attachments containing DV360 placement reports (CSV files)

How We Use It:

  • Search for and download DV360 placement reports from email attachments
  • Extract YouTube channel URLs from CSV files
  • Send automated result emails with analysis summaries and download links

Data Retention:

  • Email attachments are temporarily stored during processing (less than 60 minutes)
  • Temporary files are automatically deleted after analysis completes
  • No email content is permanently stored
  • Only extracted YouTube channel URLs are cached for future reference

YouTube Data API Access

What We Access:

  • Public channel metadata (channel name, description, subscriber count)
  • Public video titles and descriptions
  • Publicly available channel statistics

How We Use It:

  • Retrieve channel details for content categorization
  • Analyze publicly available information to assess COPPA compliance and brand safety
  • No private or restricted data is accessed

Data Retention:

  • Channel metadata is cached in Google Cloud Firestore to reduce API costs
  • Only channel URL, name, and categorization results are stored
  • No private or personal user data is collected

OpenAI API Usage

What We Share:

  • YouTube channel names and descriptions (publicly available data only)
  • Channel video titles (publicly available data only)
  • No personal information or private data

How We Use It:

  • Automated content categorization using GPT-4 AI model
  • Brand safety assessment based on publicly available content
  • Children's content detection for COPPA compliance

Data Retention:

  • OpenAI processes data according to their Privacy Policy
  • No personal information is shared with OpenAI
  • Data is used solely for API processing and not for AI model training

Data Storage

Google Cloud Firestore

What We Store:

  • YouTube channel URLs
  • Channel names (publicly available)
  • Content categorization results (children's content vs. general audience)
  • Brand safety scores
  • Analysis timestamps
  • Impression data from DV360 reports (aggregate statistics)

Purpose:

  • Cache analysis results to reduce API costs and improve efficiency
  • Maintain historical records of analyzed channels
  • Generate cumulative targeting lists for advertising campaigns

Security:

  • Data is stored in Google Cloud Platform with enterprise-grade security
  • Access is restricted to authorized service accounts only
  • All data transmission uses HTTPS encryption
  • API credentials stored in Google Cloud Secret Manager

Third-Party Services

This application integrates with the following services:

  1. Gmail API (Google)
    • Purpose: Email retrieval and sending
    • Privacy Policy: https://policies.google.com/privacy
  2. YouTube Data API (Google)
    • Purpose: Retrieving public channel metadata
    • Privacy Policy: https://policies.google.com/privacy
  3. OpenAI API
    • Purpose: Content categorization and analysis
    • Privacy Policy: https://openai.com/policies/privacy-policy
  4. Google Cloud Platform (Storage, Firestore, Cloud Functions)
    • Purpose: Application hosting and data storage
    • Privacy Policy: https://policies.google.com/privacy

Data Sharing

Important: No data is sold or shared with third parties for marketing purposes.
  • Data is only shared with service providers necessary for application functionality (Google Cloud, OpenAI)
  • All channel data analyzed is publicly available information
  • No personal user data is collected or processed
  • Analysis results are shared only with authorized Acquire NZ employees

User Rights and Control

Authorized users have the right to:

  • Revoke Gmail API access at any time via Google Account Permissions
  • Request deletion of all stored data
  • Export stored data
  • View what data has been collected

Data Retention Policy

  • Email Data: Temporary files deleted immediately after processing (within 60 minutes)
  • Firestore Cache: Retained indefinitely for cost optimization (can be cleared on request)
  • Cloud Function Logs: Retained for 30 days (Google Cloud default)
  • CSV Reports: Stored in Google Cloud Storage with signed URLs valid for 7 days

Security Measures

  • API credentials stored in Google Cloud Secret Manager (not in code)
  • Service accounts use principle of least privilege
  • HTTPS-only communication for all data transmission
  • Regular security updates to dependencies
  • OAuth 2.0 authentication for Gmail access
  • Cloud Function requires authentication (not publicly accessible)
  • Multi-factor authentication for admin access

Compliance

This application:

  • Only accesses publicly available YouTube channel information
  • Does not collect personal data from end users or viewers
  • Complies with YouTube API Terms of Service
  • Complies with Google API Services User Data Policy (including Limited Use requirements)
  • Uses Gmail API solely for authorized business email automation
  • Helps ensure advertiser compliance with COPPA regulations
